## 🔌 Connect Parry to Gemini, Claude, OpenAI Codex & Cursor

### 1. Model Context Protocol (MCP) Server (`python parry.py mcp`)
Parry includes a zero-dependency JSON-RPC 2.0 MCP server over `stdio`. Add the contents of [`mcp_config.json`](mcp_config.json) to your AI tool's configuration so your coding agent automatically calls `parry_verify_code` before finishing any edit:

- **Claude Code CLI**:
  ```bash
  claude mcp add parry -- python /path/to/parry.py mcp
  ```
- **Google Gemini CLI / IDX / Cursor / Windsurf**:
  Copy [`mcp_config.json`](mcp_config.json) into `.cursor/mcp.json` or `~/.gemini/settings.json`.
- **Drop-In Agent Rules (`AGENTS.md` / `CLAUDE.md` / `GEMINI.md`)**:
  This repository includes [`AGENTS.md`](AGENTS.md) (mirrored to `CLAUDE.md` and `GEMINI.md`) which instructs **Gemini**, **Claude Code**, and **OpenAI Codex** agents to run `python parry.py check .` and self-heal any findings automatically.

## 🚀 CLI Commands Reference

```bash
# 1. Run the 25-case Evil AI Benchmark
python parry.py bench

# 2. Scan any file or directory for AI bugs
python parry.py check path/to/code

# 3. Mute existing legacy warnings (only flag brand-new commits)
python parry.py init --baseline .

# 4. Start the MCP stdio server for AI coding agents
python parry.py mcp

# 5. Automatically repair deterministic AI hallucinations & defects
python parry.py fix path/to/code

# 6. Show agent prompt remediation patches & auto-fix diffs
python parry.py check path/to/code --fix

# 7. Machine-readable JSON, SARIF 2.1.0, or PR Shield Markdown output
python parry.py check path/to/code --format json
python parry.py check path/to/code --format sarif --output parry-results.sarif --fail-on warning
python parry.py check path/to/code --format pr-comment --diff-base origin/main --exclude tests,dist
```

## Turnkey MCP & IDE Agent Hooks (Claude, Cursor, Windsurf, Gemini, Codex)

Wire Parry directly into your AI coding agent and git commit flow in **one command** with `< 20ms` single-file feedback:

```bash
# Preview all MCP + post-edit + pre-commit hook writes safely (no disk changes)
python parry.py install-hooks --ide all --instructions --dry-run

# Configure one specific tool (claude | cursor | windsurf | gemini | codex | all)
python parry.py install-hooks --ide claude --instructions
python parry.py init --ide cursor --scope user

# Scan only files staged in git (automatically run by .git/hooks/pre-commit)
python parry.py check --staged
```

What `install-hooks` configures non-destructively (preserving your existing keys, servers, and hooks):
- **Claude Code:** `.mcp.json` + `.claude/settings.json` `PostToolUse` hook (`post-edit`) + optional `CLAUDE.md`
- **Cursor / Windsurf:** `.cursor/mcp.json` / `.windsurf/mcp.json` + optional `.cursorrules` / `.windsurfrules`
- **Gemini CLI:** `.gemini/settings.json` (`mcpServers.parry`) + optional `GEMINI.md`
- **OpenAI Codex CLI:** `.codex/config.toml` (`[mcp_servers.parry]`) + optional `AGENTS.md`
- **Git Pre-Commit:** `.git/hooks/pre-commit` running `parry.py check --staged`

## GitHub Marketplace Action & PR Shield

Drop Parry directly into any repository via `.github/workflows/parry.yml` to upload SARIF 2.1.0 alerts to the GitHub Security tab and post a single sticky `<!-- parry-pr-shield -->` review comment on pull requests (updated in place on every push):

```yaml
name: Parry PR Shield
on:
  pull_request:
  push:
    branches: [main]

permissions:
  contents: read
  pull-requests: write
  security-events: write

jobs:
  parry:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0
      - uses: AI-Ops1/Parry@v1
        with:
          paths: "."
          fail-on: "error"
          comment-pr: "true"
          changed-only: "true"
          sarif-output: "parry-results.sarif"
      - uses: github/codeql-action/upload-sarif@v3
        if: always() && hashFiles('parry-results.sarif') != ''
        with:
          sarif_file: parry-results.sarif
```
