## 🔌 Connect Parry to Gemini, Claude, OpenAI Codex & Cursor

### 1. Model Context Protocol (MCP) Server (`python parry.py mcp`)
Parry includes a zero-dependency JSON-RPC 2.0 MCP server over `stdio`. Add the contents of [`mcp_config.json`](mcp_config.json) to your AI tool's configuration so your coding agent automatically calls `parry_verify_code` before finishing any edit:

- **Claude Code CLI**:
  ```bash
  claude mcp add parry -- python /path/to/parry.py mcp
  ```
- **Google Gemini CLI / IDX / Cursor / Windsurf**:
  Copy [`mcp_config.json`](mcp_config.json) into `.cursor/mcp.json` or `~/.gemini/settings.json`.
- **Drop-In Agent Rules (`AGENTS.md` / `CLAUDE.md` / `GEMINI.md`)**:
  This repository includes [`AGENTS.md`](AGENTS.md) (mirrored to `CLAUDE.md` and `GEMINI.md`) which instructs **Gemini**, **Claude Code**, and **OpenAI Codex** agents to run `python parry.py check .` and self-heal any findings automatically.

### 2. Multi-AI BYOK Stage 3 Diff-Critic (`--provider gemini|claude|openai|codex|ollama`)
Run deep semantic verification using your own API key (zero cloud proxy, secret redaction, and indirect prompt-injection sanitization built in):

```bash
# Using Google Gemini (GEMINI_API_KEY)
python parry.py check src/ --provider gemini

# Using Anthropic Claude (ANTHROPIC_API_KEY)
python parry.py check src/ --provider claude

# Using OpenAI / Codex (OPENAI_API_KEY)
python parry.py check src/ --provider codex

# Using 100% Local Ollama (OLLAMA_HOST)
python parry.py check src/ --provider ollama
```

## 🚀 CLI Commands Reference

```bash

# 2. Scan any file or directory for AI bugs

python parry.py mcp
```

## 💾 Low on `C:` Drive Space on Windows? (`D:\Parry` Setup)

Run `.\use_d_drive.ps1` in PowerShell. It automatically redirects all `Cargo`, `Rustup`, `npm`, `pip`, `uv`, and temp caches into `D:\Parry\.cache` so building and running Parry consumes **0 bytes on your `C:` drive**.
